# Portfolio v2 "Circuit Mind" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Jekyll/Story site with a static three.js portfolio. A side-profile head has five clickable brain regions. Each region opens an e-means–clustered 3D node map of that section's items, a fully visited region turns into a PCB, a fully wired head unlocks outbound traces to "now / upcoming" cards, and there's a Markdown blog at `/writing`.

**Architecture:** Vite + TypeScript multi-page static build. Content lives in one JSON file. A build-time Python pipeline embeds the items, clusters them with e-means, reduces them to 3D and computes a nearest-neighbor tour, then writes a committed `layout.json`, so the site build never needs Python. The site is plain TS modules (profile SVG, three.js section map, reader panel, progress store, hash router). The blog is generated from Markdown by a small build script.

**Tech Stack:** Vite 6, TypeScript 5, three.js 0.17x, vitest, @playwright/test, marked, gray-matter. Python 3.12 venv with faiss-cpu ≥ 1.16 (`faiss.contrib.e_means`), sentence-transformers (`BAAI/bge-small-en-v1.5`), umap-learn, scikit-learn, pytest.

**Spec:** `docs/superpowers/specs/2026-11-13-portfolio-v2-design.md`

## Review Focus

1. **Storage unavailable** (private mode, blocked storage): site fully works and progress lives in memory for the session. Pinned in Task 3.
2. **Content changed after a visitor saved progress** (item removed or added): stale ids are ignored, and completion is computed over the current item ids, so a new item un-completes a section. Pinned in Task 3.
3. **Bad deep link** (`#projects/nope`, `#bogus`): the router falls back to the nearest valid view (`#projects`, then the profile) and never throws. Pinned in Task 2.
4. **`layout.json` out of sync with `content.json`** (Yusuf edits content and forgets the pipeline): `npm run build` fails with a message naming the missing or extra ids. Pinned in Task 4.
5. **Interrupting a transition** (Back or another click mid-dive or mid-flight): the end state always matches the current route, with no stuck overlays. Pinned in Task 7.

### Task 4: Layout pipeline (e-means) + sync check

**Files:**
- Create: `pipeline/build_layout.py`, `pipeline/requirements.txt`, `pipeline/tests/test_build_layout.py`, `scripts/check-sync.ts`, `tests/unit/check-sync.test.ts`, `content/layout.json` (generated)

**Interfaces:**
- Consumes: `content.json` (Task 1), the `Layout` type (Task 2).
- Produces: `content/layout.json` matching `Layout`, with positions normalized to fit inside radius 10. Python functions:
  - `cluster(emb: np.ndarray, k: int, seed: int) -> np.ndarray` wraps `faiss.contrib.e_means`. Read its real signature in the installed Faiss before writing this. Embeddings are L2-normalized first.
  - `choose_k(emb, seed) -> int | None`: `None` if n < 6, else the k in `2..min(6, n//2)` with the best cosine silhouette.
  - `reduce_3d(emb, seed) -> np.ndarray`: UMAP (`n_neighbors=min(5, n-1)`, cosine). Falls back to PCA if n < 6.
  - `label_clusters(texts, labels) -> dict[int,str]`: c-TF-IDF top 2 terms joined `" · "`. An override in `clusterLabelOverrides[anchorItemId]` wins, where the anchor is the member nearest the centroid.
  - `nn_tour(pos: np.ndarray, ids: list[str]) -> list[str]`: start at the node nearest the section centroid, then greedily take the nearest unvisited node.
  - `build(content: dict, seed=7) -> dict`. CLI: `python pipeline/build_layout.py` writes `content/layout.json`.
  - The `next` section is excluded from `layout.json`.
- `scripts/check-sync.ts`: `checkSync(content: Content, layout: Layout): string[]` returns problems (missing or extra ids per section). The script exits 1 and prints them, with a hint to run the pipeline.

### Task 7b: Obsidian-style 3D graph (added 11/13 per Yusuf)
